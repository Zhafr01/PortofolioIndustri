## 🚀 Deploy ke GitHub Pages

1. Buat repository baru di GitHub dengan nama `UIUXPendidikan`
2. Push semua file ke branch `main`
3. Masuk ke **Settings → Pages**
4. Set Source ke **Deploy from branch → main → / (root)**
5. Klik **Save** — site akan aktif dalam 1-2 menit!
